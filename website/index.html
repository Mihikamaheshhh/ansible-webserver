Everything the control node needs, none of the babysitting

You keep writing playbooks the way you already do. Fleetform keeps the machine that runs them online, patched, and reachable.

SYNC

Git-synced playbooks

Point Fleetform at a repo and branch. Every push is picked up automatically, with diffs shown before anything runs against production.

VAULT

Encrypted secrets at rest

Vault passwords and credentials are encrypted per-project and never appear in logs, job output, or exported artifacts.

SCHEDULE

Cron, webhook, or manual runs

Trigger a playbook on a schedule, from a CI pipeline, or by hand — with the same approval flow every time.

INVENTORY

Dynamic inventory sources

Pull hosts live from AWS, GCP, Azure, or a static file. Inventory drift shows up before a run, not during one.

ACCESS

Per-project permissions

LOGS

Full job history

From repo to running fleet

Four steps, and you never touch a bare-metal control node again.

01

Connect your repository

Authorize read access to the repo holding your playbooks, roles, and inventory files. Nothing is copied outside the run.

02

Define your inventory and credentials

Add SSH keys or cloud credentials once. They're scoped to the project and encrypted at rest.

03

Set your trigger

Choose a schedule, a webhook, or manual approval. Every run shows a plan before anything is applied.

04

Watch it run, then check the log

Live task output streams as it executes. Every past run stays searchable, with host-by-host results.
